# Отчет по нагрузочному тестированию

## 1. Общая информация
- Инструмент: k6 (локально)
- Цель: `http://localhost:8080/api/v1`
- Профиль нагрузки: 30s разгон → 4m стабильная нагрузка → 30s спад
- Максимум виртуальных пользователей (VU): 50
- Общая длительность: 5 минут

## 2. Сценарий теста и почему выбраны эти ручки
В каждой итерации выполнялись следующие запросы:
- `GET /currencies?limit=50`
  - Базовый список валют. Это главный экран приложения и самый частый запрос.
- `GET /currencies/{symbol}`
  - Детальная карточка валюты. Проверяет получение актуальной цены и метрик.
- `GET /currencies/{symbol}/history?days=7`
  - Исторические данные для графика. Нагружает расчет истории.
- `GET /portfolio`
  - Получение портфеля пользователя. Проверяет пользовательские данные.
- `GET /portfolio/stats`
  - Расчет P&L. Нагрузка на вычисления и внешний источник цен.
- `POST /favorites`
  - Добавление валюты в избранное (запись в БД).
- `GET /favorites`
  - Получение избранного (чтение из БД).
- `DELETE /favorites/{symbol}`
  - Удаление из избранного (запись в БД).

Символы для favorites генерировались уникально в каждой итерации, чтобы избежать конфликтов дублей и увидеть реальную пропускную способность записи/удаления.

## 3. Итоговые метрики
- Всего запросов: **54,888**
- Пропускная способность: **182.83 req/s**
- Средняя задержка: **121.69 ms**
- P95 задержка: **571.46 ms**
- Доля ошибок (http_req_failed): **0.01%**

## 4. Результаты по ручкам
- `GET /currencies` — OK
- `GET /currencies/{symbol}` — OK
- `GET /currencies/{symbol}/history` — 1 ошибка из 6,861 (0.01%)
- `GET /portfolio` — OK
- `GET /portfolio/stats` — 9 ошибок из 6,861 (0.13%)
- `POST /favorites` — OK
- `GET /favorites` — OK
- `DELETE /favorites/{symbol}` — OK

## 5. Выводы
Сервис стабильно выдерживает ~180 req/s при 50 VU с P95 < 600 ms и низким уровнем ошибок (~0.01%). Все ключевые пользовательские сценарии (валюты, детали, история, портфель, избранное) корректно работают под нагрузкой. Незначительные единичные ошибки наблюдались на `history` и `stats`, но не влияют на общую стабильность.
