## 👤 Полелейко Иван

### Backend задачи:
- [ ] Модели данных: Уведомления/алерты (alerts), Настройки пользователя (user_settings)
- [ ] API Endpoints для уведомлений:
  - [ ] POST `/api/alerts` - создать алерт
  - [ ] GET `/api/alerts` - список алертов
  - [ ] DELETE `/api/alerts/{id}` - удалить алерт
- [ ] API Endpoints для настроек:
  - [ ] GET `/api/settings` - получить настройки пользователя
  - [ ] PUT `/api/settings` - обновить настройки (тема, режим уведомлений)
- [ ] Бизнес-логика:
  - [ ] Логика определения значимых изменений цен
- [ ] Фоновые задачи для обновления цен (Celery или аналогичный)
- [ ] Создание миграций (Alembic или аналогичный инструмент)

### Frontend задачи:
- [ ] Страница избранного:
  - [ ] Список избранных валют
  - [ ] Быстрый просмотр цен
  - [ ] Удаление из избранного
- [ ] Страница настроек:
  - [ ] Переключатель темы (темная/светлая)
  - [ ] Выбор режима уведомлений (инвестор/трейдер)
  - [ ] Настройка алертов
- [ ] Адаптивный дизайн (мобильные устройства)
- [ ] Анимации и переходы
- [ ] Авторизация через Telegram Web App (если требуется)

### Bot задачи:
- [ ] Настройка webhook или long polling
- [ ] Команды бота:
  - [ ] `/alert {SYMBOL} {PERCENT}` - создать алерт (например, `/alert BTC 0.01`)
  - [ ] `/settings` - настройки уведомлений
- [ ] Система уведомлений:
  - [ ] Мониторинг изменений цен валют
  - [ ] Проверка условий алертов (изменение на заданный %)
  - [ ] Отправка уведомлений пользователям
  - [ ] Реализация режимов уведомлений:
    - [ ] "Инвестор" - редкие отчеты (раз в день/неделю)
    - [ ] "Трейдер" - частые сигналы (при каждом значимом изменении)
- [ ] API клиент для взаимодействия с FastAPI (алерты, настройки)
- [ ] Синхронизация пользователей (Telegram ID ↔ User ID)
- [ ] Обработка ошибок и логирование

---

### Фаза 1 (MVP):
- Backend: Модели алертов и настроек
- Frontend: Страница избранного
- Bot: Настройка бота + команда /alert
### Фаза 2:
- Backend: API алертов + логика определения изменений
- Frontend: Страница настроек
- Bot: Система уведомлений (базовая)
### Фаза 3:
- Backend: Фоновые задачи для обновления цен
- Frontend: Адаптивный дизайн + анимации
- Bot: Режимы уведомлений (инвестор/трейдер)
