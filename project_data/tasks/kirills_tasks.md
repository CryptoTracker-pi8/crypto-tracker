## 👤 Петухов Кирилл

### Backend задачи:
- [ ] Проектирование схемы БД PostgreSQL (совместно с командой)
- [ ] Модели данных: Пользователи (users), Избранные валюты (favorites)
- [ ] API Endpoints для валют:
  - [ ] GET `/api/currencies` - список популярных валют
  - [ ] GET `/api/currencies/{symbol}` - детальная информация о валюте
  - [ ] GET `/api/currencies/{symbol}/history` - история цен для графиков
- [ ] API Endpoints для избранного:
  - [ ] POST `/api/favorites` - добавить в избранное
  - [ ] GET `/api/favorites` - получить избранные валюты
  - [ ] DELETE `/api/favorites/{symbol}` - удалить из избранного
- [ ] Интеграция с API криптовалют (CoinGecko, CoinMarketCap или аналогичный)
- [ ] Кэширование данных о ценах

### Frontend задачи:

- [ ] Главная страница:
  - [ ] Список популярных валют

### Bot задачи:
